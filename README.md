# Financial Data Visualization Platform

一个基于 Vue 3 的现代化金融数据可视化平台，提供直观的数据展示和交互体验。

## ✨ 功能特点

- 📊 丰富的数据可视化图表
- 🔄 实时数据更新
- 📱 响应式设计，支持多端适配
- 🎯 可拖拽的组件布局
- 📈 高性能大数据渲染
- 🎨 美观的 Material Design 风格界面

## 🛠️ 技术栈

- **前端框架**: Vue 3
- **构建工具**: Vite
- **UI 组件库**: 
  - Element Plus
  - Vuetify 3
- **图表库**: ECharts
- **样式处理**: 
  - Tailwind CSS
  - SASS
- **工具库**:
  - Axios (HTTP 请求)
  - Lodash (工具函数)
  - Vue Router (路由管理)
- **其他特性**:
  - Markdown 支持
  - 虚拟滚动
  - 组件拖拽

## 🚀 快速开始

### 环境要求

- Node.js >= 16.0.0
- npm >= 7.0.0

### 安装

```bash
# 克隆项目
git clone [项目地址]

# 进入项目目录
cd financial_data_vue

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 构建部署

```bash
# 构建生产环境版本
npm run build

# 预览生产环境版本
npm run preview
```
